What a real coach told us

Jump the queueno cost

A GB international 10km runner — an elite coach — used the app and sent six things back. Every one was checked against the actual code and every one was real; three turned out to be worse than he described. This is the most valuable feedback the project has had, because it is the difference between a plan that looks right and one a coach would stand behind.

Why this is first: the race-day problem is the only thing on this map that could send someone into a goal race having done hard intervals the day before. That gets fixed before anything cosmetic.
1

Get set up to build real iPhone apps

≈ 1–2 weeks£79 / year

A web app can't go in the App Store or talk properly to watches. To get there, Inte-Run needs to become a "native" app — one built with Apple's own tools. This phase is just getting those tools ready.

Watch out: Xcode needs a reasonably up-to-date Mac with plenty of free disk space (think 50 GB+ free). Check that before paying for anything.
2

Inte-Run in the App Store

≈ 2–4 monthsThe big one

Rebuild the app as a real iPhone app. It's less scary than it sounds: the training brain — the part that builds plans and adapts them — is already written as pure logic with 122 automatic checks, and moves across largely as-is. What gets rebuilt is the screens.

Watch out: health-adjacent apps get extra scrutiny in review. The app's careful "this is not medical advice" behaviour — which it already has — needs to survive the move.
3

Apple Watch

≈ 1–3 monthsShips as an update

The watch is where a running app earns its keep: leave the phone at home, run the session from your wrist, and gain heart-rate — a signal the app has never had before.

Watch out: you'll need a real Apple Watch to test on — simulators can't produce genuine GPS or heart-rate. Budget for one if you don't own one.
4

The intelligent coach

≈ 1–2 monthsCan start now, in the web app

This is the flags system you described — and it doesn't have to wait for the App Store, because it's pure training logic. Version 1 already exists: the app re-estimates fitness from your runs and asks before changing anything. This phase completes it.

Watch out: the temptation is to add ten more flags. Two done brilliantly beats ten done half-well — more can come later once these have earned trust.
5

Garmin watches

≈ 2–4 monthsServer ≈ £10–50 / month

Garmin is a different world from Apple: their watches talk to Garmin's own system, and Garmin's system talks to yours. That means two firsts — asking Garmin's permission, and running a small server (a computer on the internet that receives run data for the app).

Watch out: once a server holds people's run data, you've taken on real responsibility — backups, security, and UK data-protection rules. Small and boring is the right shape for this server.
6

Community — find runners like you

≈ 3–6 monthsThe most sensitive build

Matching people of similar ability nearby so they can meet and run together. Technically it builds on Phase 5's accounts and server. But the real work here is safety — this is the one feature where a mistake can hurt someone in the real world, so safety features ship first, not last.

Watch out: this is the phase where "just ship it" is the wrong instinct. A community feature launched without moderation and reporting doesn't just fail — it can genuinely harm someone. Slow is right here.
7

Keeping it alive

Ongoing

A live app is a rhythm, not a finish line. This phase never completes — and that's the point.
